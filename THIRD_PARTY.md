## Development-only packages (not shipped)

pytest, pytest-cov, hypothesis, scipy, httpx and jsonschema are used only to test the project. They are not part of the
running application.

## Language model (optional, not bundled)

| Item | Licence | How it is used |
|---|---|---|
| Phi-4-mini (Microsoft) | MIT, shown in the licence text that Ollama ships with the model (`ollama show phi4-mini --license`) | The optional local Explainer model; downloaded by the user with `ollama pull phi4-mini`, never stored in this repository |
| Ollama | MIT | Runs the model locally; installed by the user, not bundled |

The files in `data/recorded/` contain sentences that Phi-4-mini wrote for synthetic matches. They contain no model
weights. An earlier trial used Qwen2.5-3B, whose Qwen Research License allows non-commercial research and evaluation
use only; it was dropped, and none of its output is in this repository.

## Data, text and media

- All matches, clubs and players are generated by `src/matchdesk/generator.py`. No real club, player, crest, photo, video
  or broadcast footage is used, and no real club or player name appears.
- "Premier League" appears only as plain text where the challenge itself is named. No crest, logo or trademarked artwork
  is used.
- The renderer in `web/` is plain HTML, CSS and JavaScript with no external script, stylesheet, font or image, and it
  makes no request to any other origin. Fonts come from the visitor's system font stack.
- No music or sound is included.
